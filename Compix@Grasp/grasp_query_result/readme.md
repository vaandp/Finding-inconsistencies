This directory contains the extracted results of GRASP-generated SPARQL queries executed over the precomputed Wikidata index.

The precomputed Wikidata index can be downloaded from:  
[Download link](https://ad-publications.cs.uni-freiburg.de/grasp/kg-index/wikidata.tar.gz)

These indices are what GRASP uses locally at runtime. According to the GRASP documentation, they were originally generated by running SPARQL queries against the QLever Wikidata endpoint:  
[QLever Wikidata endpoint](https://qlever.cs.uni-freiburg.de/api/wikidata)
